# 대진대학교 팀플 밸런서 (Daejin University Teamplay Balancer)

이 앱은 대진대학교 학생들이 조별과제(팀플)를 진행할 때 생기는 불공평한 역할 분담과 프리라이더 문제를 데이터 기반으로 해결하고, 본인의 활동 이력을 관리하기 위해 개발된 웹앱 및 PWA(Progressive Web App) 서비스입니다.

## 주요 기능
1. **회원가입 및 로그인**: 영문+숫자 8자 이상 비밀번호 검증과 가입 즉시 대시보드 자동 진입.
2. **내 팀플 메인 대시보드**: 개설한 팀플 방과 참여한 팀플 방의 실시간 상태 및 과거 배정 결과 관리.
3. **팀플 방 생성 및 초대 링크**: 카카오톡 등으로 전송할 수 있는 고유 초대 링크 생성 및 클립보드 복사.
4. **토스형 단계별 성향 설문**: 한 화면에 하나의 질문만 표시해 응답 피로도를 낮춘 선형 UI.
5. **가중치 기반 자동 매칭 알고리즘**:
   - **Rule 1 (디자인 전공 우선)**: 디자인 관련 학과이면서 PPT 제작을 선호하면 PPT 메인 제작자로 최우선 매칭.
   - **Rule 2 (조장 선정)**: 목표 학점 "A+ 멱살캐리형" 가중치(+5) 및 동률 시 고학번 선배 우선 추천(+3).
   - **Rule 3 (시간적 여유)**: "바쁨/매우 바쁨" 선택 조원은 긴 호흡의 PPT나 조장 제외, 발표 및 자료조사 위주 배정.
   - **Rule 4 (데드락 방지)**: 난수(Random Salt)를 활용해 동률 분배하되, 기피 항목 조율 발생 시 "개입 알림" 노출.
6. **30일 보관 규칙**: 서버 리소스 관리 및 개인정보 보호를 위해 방 생성일 기준 30일 경과 데이터는 백그라운드에서 주기적으로 영구 삭제.

## 프로젝트 구조
- `public/`: 웹앱 프론트엔드 리소스 (HTML, CSS, JS, manifest.json, sw.js)
- `server/`: Node.js Express 백엔드 리소스
  - `server.js`: API 라우트 및 정적 파일 서버
  - `db.js`: 경량 파일 데이터베이스 (데이터 저장용 `data.json` 자동 생성)
  - `matcher.js`: 가중치 연산 매칭 알고리즘
  - `test-matching.js`: 알고리즘 검증용 테스트 스크립트
- `package.json`: NPM 라이브러리 및 실행 스크립트 정의

## 실행 방법

### 1. 의존성 패키지 설치
프로젝트 폴더 내에서 다음 명령어를 실행하여 필요한 NPM 패키지들을 설치하세요:
```bash
npm install
```

### 2. 서버 실행
개발 서버를 구동합니다:
```bash
npm start
```
서버가 시작되면 웹 브라우저를 열고 **`http://localhost:3000`**에 접속하여 서비스를 이용하실 수 있습니다!

### 3. 알고리즘 테스트 실행 (선택사항)
매칭 가중치 알고리즘의 동작을 로컬에서 별도로 검증하고 싶다면 다음 명령어를 실행하세요:
```bash
npm run test-match
```
결과 출력으로 정상적인 매칭 및 데드락 상황에서의 시스템 개입 상태가 정확하게 구현된 것을 확인할 수 있습니다.
